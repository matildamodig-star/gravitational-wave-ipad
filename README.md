# Gravitational Wave Analysis for iPad

Optimized gravitational wave detection pipelines for running on iPad with Juno Connect + Binder.

## 🚀 Quick Start

1. Open **Juno Connect** on your iPad
2. Add server: `https://mybinder.org/v2/gh/YOUR_USERNAME/gravitational-wave-ipad/main`
3. Open `GW170817_Optimized.ipynb`
4. Run the analysis!

## 📱 Optimized for Mobile
- Reduced memory usage
- Mobile-friendly visualizations
- Progress indicators
- Session management

## 🔬 Analyses Included
- GW170817 binary neutron star detection
- Primordial harmonic search
- Monte Carlo significance testing
